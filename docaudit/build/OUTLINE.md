# Cấu trúc chuyên đề tái cấu trúc — bản 2.0

Mục tiêu: ≥ 45.000 từ phần thân (không kể tài liệu tham khảo), 4 cấp tiêu đề,
~34 bảng, 11 hình (dùng lại hình sẵn có), ~160 tài liệu tham khảo.

Ký hiệu: [T] = bảng mới hoặc giữ lại; [F] = hình; (n) = số từ mục tiêu.
